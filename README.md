# Mis Gastos

App web simple (PWA) para anotar tus gastos: monto, categoría, descripción y fecha. Muestra el total del mes, el desglose por categoría y te deja exportar todo a CSV. Los datos quedan guardados solo en tu dispositivo (localStorage) y funciona sin conexión.

## Publicar en GitHub Pages

1. En el repo: Settings → Pages → Source: **GitHub Actions**.
2. Hacé push a `main` (o a la rama configurada en `.github/workflows/pages.yml`).
3. La app queda en `https://<usuario>.github.io/demo/`.

## Instalar en el iPhone

1. Abrí la URL en **Safari**.
2. Tocá **Compartir** → **Agregar a pantalla de inicio**.
3. Abrila desde el ícono nuevo.
